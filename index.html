PipeForge↗

A reusable pipeline framework that keeps build logic in one YAML definition, with execution locally and through GitHub Actions, GitLab CI or Jenkins.

Makes pipeline behavior easier to reproduce and debug across environments. The Python implementation includes dependency validation, execution reports and resumable runs.
